# Smart Pantry Manager

Java Android application for Mobile App Development 700.

## Features
- Pantry CRUD
- SQLite persistence
- RecyclerView custom adapters
- 20 seeded recipes
- Strict recipe matching
- Recipe detail
- Settings screen

## Database
SQLite was selected because it provides local persistent storage without requiring a separate server.

## Setup
1. Open the project in Android Studio.
2. Allow Gradle to sync.
3. Run the app on an Android emulator/device.
4. Add pantry ingredients.
5. Open Suggested Recipes.
